# Himalayan Expedition Analysis | Power BI

An interactive Power BI dashboard analysing historical Himalayan expedition data to explore expedition trends, peak performance, associated risks and climber demographics.

# Project Objective
To transform historical expedition data into meaningful insights and identify patterns in expedition outcomes, regional performance and climber participation.

# Tools & Technologies
- Power BI
- Power Query
- DAX
- API-sourced data

# Dashboard Overview

1. Himalayan Expedition Intelligence
- Analyses expedition volumes, yearly trends, popular peaks, outcomes and seasonality.

2. Peak Explorer
- Compares peak elevations, expedition success rates and regional distribution.

3. Risk & Expedition Performance
- Examines regional risks, seasonal performance, mortality patterns and expedition termination reasons.

4. Climber & Expedition Profile
- Explores climber participation, nationality trends, team composition and active climbers.

# Key Features
- Interactive filters and slicers
- Dynamic KPI cards
- Comparative visualisations
- Historical trend analysis
